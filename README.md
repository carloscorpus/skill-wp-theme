# wp-vite-theme

Skill para Claude Code: scaffold de tema WordPress (Local WP) con Vite + JS + Tailwind + pnpm.

## Instalación

```bash
# solo proyecto actual (.claude/skills)
npx skills@latest add carloscorpus/skill-wp-theme

# global, todos los proyectos (~/.claude/skills)
npx skills@latest add carloscorpus/skill-wp-theme -g
```

## Uso

En Claude Code: "inicia tema", "nuevo tema wp" o `/wp-vite-theme`.
